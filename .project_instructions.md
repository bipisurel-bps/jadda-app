# Jadda (جدّ) - Project Instructions

## Overview
Progressive Web App (PWA) bernama "Jadda" (جدّ) — Aplikasi Islami Ringkas: Doa, Hadits, Zakat, Waris & Umrah. Bahasa Indonesia. Sebelumnya "Doa & Waris" → "Jariyah" → "Jadda" di v2.0. Filosofi: Jadda (جدّ) = Bersungguh-sungguh.

## Design & Theme
- Clean, modern, minimalist, Islamic, informative
- Primary: Emerald green (#1B6B4A), Accent: Gold (#C9A84C)
- Font Arabic: Amiri (serif), Font Latin: DM Sans & Plus Jakarta Sans
- Dark mode support with toggle
- Mobile-first, responsive, bottom nav mobile, top nav desktop
- Subtle Islamic geometric ornaments

## Features
1. **Doa Harian** - 161 kategori, 310 doa dari Hisnul Muslim
   - Data: `/public/data/prayers.json`
   - Search, filter, bookmark (localStorage), copy Arabic
2. **Hadits Arbain An-Nawawi** - 42 hadits pilihan (An-Nawawi + Ibnu Rajab) dengan kandungan
   - Data: `/public/data/hadits-arbain.json`
   - Accordion UI, search, favorites
3. **Kalkulator Zakat** - 5 jenis: maal, fitrah, perdagangan, pertanian, peternakan
   - Logika: `/lib/zakat.ts`
   - Maal & perdagangan: user input harga emas per gram (tidak hardcode)
   - Peternakan: unta, sapi/kerbau, kambing/domba dengan tabel nisab lengkap
4. **Kalkulator Waris (Faraidh)** - Lengkap sesuai Al-Qur'an & Sunnah
   - Logika: `/lib/faraidh.ts`
   - Ashabul Furudh, Ashabah, Hajb, Aul, Radd, Al-Umariyyatain
   - Pie chart (recharts), tabel hasil, dalil Qur'an
   - **PENTING: Tidak menyebut mazhab tertentu**
5. **Panduan Umrah** - 10 langkah tata cara umrah
   - Data: `/public/data/panduan-umroh.json`
   - Doa & bacaan Arab lengkap dengan transliterasi
   - 2 mode tampilan: Accordion (semua langkah) dan Stepper (satu per satu)
6. **Panduan Haji** - 10 langkah, dari Mulakhos Fiqhi (Syaikh Shaleh Al-Fauzan)
   - Data: `/public/data/panduan-haji.json`
7. **Waktu Sholat & Dzikir** - Aladhan API (method 20 / Kemenag RI)
   - `/app/(main)/sholat/` — pakai GPS, countdown next prayer, notifikasi dzikir pagi/petang
8. **Arah Kiblat (Qibla Compass)** — ditambahkan di v2.3
   - Page: `/app/(main)/qibla/`, lib: `/lib/qibla.ts`
   - Great-circle bearing ke Ka'bah (21.4225°N, 39.8262°E)
   - Haversine distance ke Makkah
   - Sensor: `deviceorientationabsolute` (Android) + `webkitCompassHeading` (iOS) + fallback `deviceorientation`
   - iOS: `DeviceOrientationEvent.requestPermission()` dari user gesture
   - Reverse geocode lokasi via Nominatim (OpenStreetMap) untuk label kota
   - Low-pass filter 25% untuk redam jitter sensor
   - Compass rose rotates, label N/E/S/W counter-rotate agar tetap tegak
   - Status "Menghadap Kiblat ✓" dalam toleransi 5°, else "Putar X° menuju kiblat"
   - Kalibrasi warning jika sensor non-absolute
9. **PWA** - manifest.json, service worker (sw.js v6, termasuk /qibla), offline capable
10. **Branding**: Nama "Jadda" (جدّ), logo pohon+tangan (jadda small.png), favicon جدّ (emerald+gold SVG)

## Technical
- Next.js 14+ App Router, TypeScript, Tailwind CSS
- No database — semua data client-side (localStorage + JSON)
- Chart: recharts library
- Animation: framer-motion (gunakan hati-hati untuk avoid contrast issues)

## User Preferences
- Akurasi konten adalah prioritas utama
- Tidak menyebut mazhab spesifik pada kalkulator waris
- Aplikasi akan dipublikasikan untuk umum
