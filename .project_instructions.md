# Doa & Waris - Project Instructions

## Overview
Progressive Web App (PWA) bernama "Doa & Waris" — Panduan Doa & Perhitungan Waris Islami. Bahasa Indonesia.

## Design & Theme
- Clean, modern, minimalist, Islamic, informative
- Primary: Emerald green (#1B6B4A), Accent: Gold (#C9A84C)
- Font Arabic: Amiri (serif), Font Latin: DM Sans & Plus Jakarta Sans
- Dark mode support with toggle
- Mobile-first, responsive, bottom nav mobile, top nav desktop
- Subtle Islamic geometric ornaments

## Features
1. **Doa Harian** - 105 doa dari 45 kategori Hisnul Muslim
   - Data disimpan di `/public/data/prayers.json`
   - Search, filter by category, bookmark (localStorage)
   - Copy Arabic text, favorites page
2. **Kalkulator Waris (Faraidh)** - Lengkap sesuai Al-Qur'an & Sunnah
   - Logika di `/lib/faraidh.ts`
   - Ashabul Furudh, Ashabah, Hajb, Aul, Radd, Al-Umariyyatain
   - Pie chart (recharts), tabel hasil, dalil Qur'an
   - **PENTING: Tidak menyebut mazhab tertentu** — hanya "sesuai Al-Qur'an dan Sunnah"
3. **PWA** - manifest.json, service worker (sw.js), offline capable

## Technical
- Next.js 14+ App Router, TypeScript, Tailwind CSS
- No database — semua data client-side (localStorage + JSON)
- Chart: recharts library
- Animation: framer-motion (gunakan hati-hati untuk avoid contrast issues)

## User Preferences
- Akurasi konten adalah prioritas utama
- Tidak menyebut mazhab spesifik pada kalkulator waris
- Aplikasi akan dipublikasikan untuk umum
