# Doa & Waris - Project Instructions

## Overview
Progressive Web App (PWA) for Islamic prayers (doa) from Hisnul Muslim and Islamic inheritance calculator (faraidh).

## Design System
- **Primary**: Emerald green (HSL 153 60% 26% / ~#1B6B4A)
- **Accent**: Gold (HSL 43 50% 54% / ~#C9A84C)
- **Arabic font**: Amiri (via Google Fonts import in globals.css)
- **Theme**: Clean, modern, minimalist Islamic design with subtle geometric patterns
- **Dark mode**: Supported via next-themes with class-based switching

## Architecture
- Next.js 14 App Router with route group `(main)` for all pages
- `AppShell` component: responsive navigation (sticky top for desktop, bottom bar for mobile)
- All interactive pages use client components in `_components/` subdirectories
- Prayer data: static JSON at `/public/data/prayers.json` (15 categories from Hisnul Muslim)
- Inheritance calculation: pure TypeScript function in `lib/faraidh.ts`
- No database needed - localStorage for bookmarks and theme preference

## Pages
- `/` - Homepage with Islamic greeting, daily verse, feature cards
- `/doa` - Prayer list with search, filter by category, bookmark/favorite, copy Arabic text
- `/waris` - Inheritance calculator with complete faraidh logic (Ashabul Furudh, Asabah, Hajb, Aul, Radd, Umariyyatain)
- `/tentang` - About page with references and credits

## PWA Features
- `manifest.json` in public/
- Service worker (`sw.js`) for offline caching
- Theme color: #1B6B4A

## Key Libraries
- recharts for pie chart visualization in waris results
- framer-motion for animations
- sonner for toast notifications
- next-themes for dark mode

## Language
- UI language: Indonesian
- Arabic text uses Amiri font with RTL direction
